# Meme Codex

> A visual encyclopedia of 100+ internet memes from around the world — for the generation that lived through them.

## About

This is a curated reference of 100+ internet memes — their origins, meanings, peak years, and where they came from. Aimed at millennials who want to understand what their kids / timeline / group chat is referencing, without the chaos of TikTok.

## Structure

- `index.html` — single-page encyclopedia
- `style.css` — dark theme, yellow accent, StillsLab-inspired
- `app.js` — search, filter, modal detail view
- `data/memes_en.js` — 60 English-language / Western memes
- `data/memes_intl.js` — 40+ international memes (Japan, Korea, China, France, etc.)

## Coverage

- **USA / UK** (Western internet) — Doge, Pepe, Distracted Boyfriend, Rickroll, Grumpy Cat, etc.
- **Japan** — Yakuza, Vocaloid, Kuso, 2ch, etc.
- **Korea** — KakaoTalk emoticons, PSY Gangnam Style, etc.
- **China** — Bilibili study meme, Lei Jun "Are you OK?", etc.
- **France / Germany / Russia** — regional meme culture
- **Latin America** — Brazilian WhatsApp, Mexican slang, etc.

## Sources

- [Know Your Meme](https://knowyourmeme.com) — primary source for image URLs and origin data
- [Wikipedia](https://en.wikipedia.org) — cultural context
- Major news outlets — peak-year verification

## Run locally

Just open `index.html` in a browser. No build step, no dependencies.
